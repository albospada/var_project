
# VAR Project - Barman Skills

## Synopsis

Barman Skills is an educational Virtual Reality project designed for students and trainees in hospitality and culinary programs. It aims to bridge the gap between theoretical knowledge and practical bartending through an immersive, risk-free simulation of a professional bar.

Users will learn about spirits, liqueurs, and fresh ingredients through interactive learning modules. They will then practise preparing essential classic cocktails by selecting the appropriate glassware, choosing the correct ingredients, measuring precise quantities, and performing fundamental techniques such as stirring and shaking.

The experience will also address ice handling, preparation timing, and time management under pressure, helping learners develop skills relevant to professional bartending.
